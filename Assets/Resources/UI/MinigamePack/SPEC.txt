■ 컨테이너 상태 6종

  locked   잠김 — X 표시, 코드 점 소등
  correct  정답 — 앰버 강조 + 글로우
  wrong    오답 — 레드 강조 + 글로우

  * 가운데 화면은 비어 있는 컨테이너입니다.
    기존 무기 실루엣 아이콘을 그대로 얹으면 됩니다.
    아이콘 영역 = 스프라이트 기준 (54, 50) ~ (378, 198)  / 324 x 148
