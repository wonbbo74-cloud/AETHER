## 🎮 게임 흐름

```text
시작 화면 → 플레이어 선택 → 로딩 → 튜토리얼
   → 폐허가 된 도시 → 연구소 메인 → 파츠 제작실
   → 1구역 → 2구역 → 3구역(고열실)
```

- 구역마다 적을 모두 처치하면 클리어가 기록되고, 엘리베이터에서 다음 구역 층이 열립니다.
- 구역 사이에는 시네마틱 장면(벙커 대화, 로봇 앞, 연구소 앞)이 들어갑니다.

## ✨ 핵심 시스템

| 시스템 | 설명 |
|---|---|
| **두 명의 플레이어 캐릭터** | **한결**과 **윤서** 중 한 명을 골라 시작합니다. 캐릭터마다 이동·전투 방식과 파츠 능력이 다릅니다. |
| **파츠 장착** | 파츠 제작실에서 만든 파츠로 슈퍼 점프, 방패, 브레이커 같은 능력을 바꿔 끼웁니다. 점프 코스 높이와 간격은 이 능력 수치에 맞춰 설계했습니다. |
| **적 AI** | 드론은 순찰 → 소리를 듣고 조사 → 돌진 자폭 순서로 움직이고, 로봇과 터렛이 함께 등장합니다. 플레이어가 내는 소리가 적의 경계 단계를 올립니다. |
| **퍼즐 + 난이도 자동 조절** | 회로 연결 퍼즐과 코드 해독 퍼즐이 있고, 플레이어가 막히면 개입 시점에 맞춰 난이도를 낮춰 주는 DDA(동적 난이도 조절)를 넣었습니다. |
| **구역 진행** | 엘리베이터와 구역 클리어 기록으로 진행을 관리합니다. |
| **연출·UI** | 미니맵, 나침반, 경계 단계 표시, 화면 흔들림, 장면 전환 페이드, Cinemachine·Timeline 시네마틱 |

```text
├── 0. Scenes/          # 게임 씬 (01.스타트씬 ~ 11.3구역, Cinematic/)

│   ├── PartsSystem/    #   파츠 장착·능력
│   ├── Puzzle/         #   회로·코드 해독 퍼즐, 난이도 조절
│   ├── Drones/ Robots/ Turrets/   # 적
│   ├── SceneFlow/      #   구역 진행, 전투 배치
│   └── Cinematic/ UI/ Elevator/ Interaction/ ...
├── _AETHER_Project/    # 프리팹·UI·오디오·데이터 정리 폴더
├── 6. Prefabs/  7. UI/  5. Sound/
└── Resources/          # 실행 중 불러오는 오디오·FX·HUD·퍼즐 데이터
```

## ▶️ 실행 방법

1. Unity Hub에서 **Unity 6000.2.12f1**로 프로젝트를 엽니다.
2. `Assets/0. Scenes/01.스타트씬.unity`를 열고 Play를 누릅니다.

### ⚠️ 외부 에셋은 들어 있지 않습니다

Asset Store 등에서 받은 외부 에셋 팩은 **라이선스와 용량(약 30GB) 때문에 올리지 않았습니다.**
그래서 클론한 뒤 그대로 열면 해당 팩을 쓰는 모델·머티리얼·텍스처가 빠져 보입니다.
제외 목록은 `.gitignore`의 "외부 에셋 팩" 항목에 있고, 같은 팩을 같은 폴더 위치에 다시 가져오면 연결이 복구됩니다.

이 저장소에 들어 있는 것은 직접 만든 스크립트, 씬, 프리팹, UI, 데이터와 `Packages`, `ProjectSettings`입니다.
